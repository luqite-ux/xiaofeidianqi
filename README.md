# XIAOFEIDIANQI Website

Premium English B2B inquiry website for Hangzhou Xiaofei Electrical Appliance Co., Ltd.

## Local Commands

```bash
pnpm install
pnpm test
pnpm build
pnpm dev -- --hostname 127.0.0.1 --port 3101
```

## Delivery Notes

- Visible launch language: English.
- Content structure is ready for later multilingual expansion.
- The site is B2B inquiry-oriented and does not include retail commerce flows.
- Product pages and CTA buttons route users to `/contact#inquiry`.
- The uploaded XIAOFEIDIANQI logo is used for the header and app icon.
